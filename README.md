## 👋 About This Repository

This repository documents my **Artificial Intelligence & Machine Learning 30-day intensive learning journey** into Data Science and Analytics — committing to one structured study session every day, tracked and versioned through GitHub.

I come from a background in **Human Resources**, where I spent years working with people data, workforce planning, and organisational processes. I built this repository to demonstrate that I don't just understand data in theory — I can work with it hands-on, write clean Python, query databases, and build models from scratch.

> **What this repo proves:** Discipline, structured thinking, and the ability to independently acquire technical skills — exactly what you'd want in a Data Analyst or HR Tech Consultant.

## 🗺️ Learning Roadmap

The curriculum spans **four progressive phases**, from Python fundamentals all the way to deep learning:

### Phase 1 — Python Foundations & Data Tooling *(Days 6–9)*
| Day | Topic | Key Skills |
|-----|-------|-----------|
| 6 | Modules & Libraries | NumPy, Pandas, Matplotlib — the core data stack |
| 7 | Pandas Deep Dive | DataFrames, filtering, groupby, aggregation |
| 8 | Data Visualisation | Matplotlib, Seaborn — turning numbers into stories |
| 9 | Practice Data Analysis | End-to-end EDA on real datasets |

### Phase 2 — Statistics & Mathematics for Data *(Days 10–14)*
| Day | Topic | Key Skills |
|-----|-------|-----------|
| 10 | Descriptive Statistics | Mean, median, variance, distributions |
| 11 | Probability | Bayes' theorem, probability distributions |
| 12 | Correlation & Covariance | Measuring relationships between variables |
| 13 | Linear Algebra | Vectors, matrices — the language of ML |
| 14 | Calculus for ML | Gradients, derivatives, optimisation intuition |

### Phase 3 — Data Engineering & SQL *(Days 15–19)*
| Day | Topic | Key Skills |
|-----|-------|-----------|
| 15 | Data Cleaning | Handling nulls, duplicates, type casting |
| 16 | Outlier Handling | IQR, Z-score, Git branching workflow |
| 17 | Data Storytelling with SQL | Writing queries that answer business questions |
| 18 | PostgreSQL | Relational databases, joins, window functions |
| 19 | Advanced EDA Project | Full exploratory analysis + visualisation project |

### Phase 4 — Machine Learning & AI *(Days 20–30)*
| Day | Topic | Key Skills |
|-----|-------|-----------|
| 20 | ML Foundations | Supervised vs unsupervised, train/test split |
| 21 | Feature Engineering | Encoding, scaling, selection |
| 22–23 | Regression Models | Linear & logistic regression, evaluation metrics |
| 24–25 | Decision Trees | Classification, pruning, Gini impurity |
| 26 | KNN & Naive Bayes | Instance-based & probabilistic classifiers |
| 26 | Unsupervised Learning | K-Means clustering, dimensionality reduction |
| 27 | Deep Learning & Neural Networks | Perceptrons, backpropagation, activation functions |
| 28 | PyTorch Framework | Building and training neural networks |
| 29–30 | CNNs & Mini Projects | Convolutional networks + capstone projects |
